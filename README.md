# HR Analytics Dashboard - Power BI

An interactive HR Analytics dashboard built in Power BI to analyze employee data and understand attrition patterns.

## Dashboard Preview


![Dashboard View 1](HR%20ANALYTICS%20SS.png)





![Dashboard View 2](HR%20ANALYTICS%20F2%20SS.png)



## Key Metrics
- Total Employees: 1,417
- Active Employees: 1,186
- Attrition Count: 231
- Attrition Rate: 16.3%
- Average Age and Average Experience

## Analysis Included
- Attrition by Department
- Attrition by Salary Slab
- Attrition by Job Role and Job Satisfaction
- Attrition by Gender
- Attrition Trend by Experience
- Age Group Distribution
- Department-wise Employee Count

## Features
- Department and Age Group filters (slicers)
- 6 KPI cards built with DAX measures
- Interactive charts for attrition analysis

## Tools Used
Power BI, Microsoft Excel
